# Poker Lab v0.2 — 完全ローカル・ポーカーAI対戦＆練習アプリ

**対象**: 1対1のNo-Limit Texas Hold'em。ベット・レイズ・コール・フォールド、ターン進行、ショーダウン、オールインの自動ランアウトに対応。
**重要**: 搭載する `EquityBot` は確率計算を利用したルールベースの対戦相手であり、GTO Botでも学習済みの強いAIでもありません。

## 最短で起動する

- Python 3.11以上を用意する。
- **このREADMEのあるディレクトリ**でターミナルを開く。
- 下のコマンドを実行する。

```bash
python -m pokerlab.server
```

通常はブラウザが自動で開きます。開かない場合は `http://127.0.0.1:8765` を開いてください。終了は `Ctrl+C`。

**サーバー代0円**: 外部サーバー、ネットワークAPI、pipインストール不要。ローカルPCの `127.0.0.1` だけにバインドします。データはメモリ上で保持するため、Pythonを停止すると対戦履歴は消えます。

## ゲーム仕様

- 2人、各ハンド200チップ、SB=1、BB=2。ボタンはハンドごと交互。
- 1ハンドごとに持ち点を200へ再設定（練習用。実際のキャッシュゲームの持ち点を継続するモードではない）。
- ベットは整数チップ単位、レーキなし、アンティなし。
- レイズ上限は相手にマッチしてもらえる実効スタックまで。フルレイズに足りない場合はショートオールインのみ許可。
- 2人対戦でどちらかがオールインしたら、自動で残りのボードを公開しショーダウン。
- ルールチェックは統合テストを用意していますが、本番競技用に使う前にはPokerKitなどの独立実装と追加の突き合わせを推奨。

## 解析の範囲と限界

- `Decision Lab` は人間が行動を選択した**直前**の自分のホールカード、場のカード、ポット、コール額を保存する。
- その情報で、**ランダムな合法2枚**に対する勝率をモンテカルロで約550試行計算。
- エクイティ = P(勝ち) + 0.5×P(引き分け)。コール必要率 = `call / (pot + call)`（potは相手のベットを含み、自分のコール前）。
- 単純コールEV = `equity × (pot + call) − call`。**相手のハンドレンジ、将来のベット、フォールドエクイティ、レイズのEVを含まない**。したがって、真の最適アクションやGTO後悔値と呼ばない。
- 誤差区間は単純な正規近似。相手モデルの不適切さによる体系誤差は表していない。

## ベンチマーク

```bash
python -m pokerlab.bench --hands 200 --seed 42 --trials 120
```

`EquityBot` vs `RandomBot` の成績をbb/100と簡易95%区間で表示。ハンド間の独立性を仮定した粗い区間であり、強い人間に勝てる保証にはならない。高い分散を考慮し、今後はボード・配牌をそろえるペア比較と複数相手モデルを追加すべき。

## ゲーム理論の実験：CFRを数値で確認する

```bash
python -m pokerlab.kuhn_cfr --iterations 20000 --seed 123
```

3枚のKuhn Poker（Texas Hold'emとは別の極小ゲーム）でCFRを学習し、全ての私的カード分配と純粋戦略に対するベストレスポンスを列挙して `NashConv` を評価します。0に近いほど互いに悪用しにくい戦略です。

再現した一例（seed 123、20,000 iterations）：P0の期待損益 `-0.05578`、理論値 `-1/18 ≈ -0.05556`、NashConv `0.01462`。これは**極小ゲームにおけるCFR実装の検証**であって、本物のHold'emの強さを意味しません。
